# Improvement Roadmap

- **Order Tests** — Add coverage for order creation, authorization, and stock failures.
- **Inventory Module** — Improve stock reservation and inventory tracking.
- **Checkout Module** — Add stronger duplicate-order protection and clearer errors.
- **Authentication Module** — Replace client session state with secure server sessions.
- **Admin Authorization** — Enforce role permissions across every admin operation.
- **Product Tests** — Cover MongoDB product CRUD and Cloudinary image handling.
- **Category Module** — Expand persisted category management and validation.
- **Customer Module** — Move profiles and customer records fully into MongoDB.
- **Order Notifications** — Add email updates for confirmations and status changes.
- **Production Setup** — Configure environment variables, monitoring, backups, and deployment.
